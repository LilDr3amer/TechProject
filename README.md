# Консольная программа для обработки массива

## Описание
Программа на C++ для ввода и обработки массива целых положительных чисел. 
Определяет минимальное, максимальное и среднее арифметическое значения.

## Требования
- Компилятор C++ (g++, MSVC, clang++)
- Стандарт C++11 или выше


## Как работает
1. Программа запрашивает размер массива (только 10).
2. Пользователь вводит 10 положительных целых чисел.
3. Каждый ввод проверяется:

- буквы и символы — отклоняются;

- отрицательные и ноль — отклоняются;

- дробные числа — отклоняются.

4. В конце выводятся:

- минимальное значение;

- максимальное значение;

- среднее арифметическое (с двумя знаками после запятой).

## Как собрать
g++ Project1.cpp -o program

## Как запустить
./program

## Как запустить в Visual Studio
1. Открыть Project1.cpp в Visual Studio
2. Нажать F5 (или Ctrl+F5 для запуска без отладки)
